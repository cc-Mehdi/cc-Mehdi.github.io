# هویت افزا — درگاه رشد

نماد از دو درگاه هندسی پیوسته و یک قطعه نارنجی رو به بالا تشکیل شده است: مسیر ورود ایده، ساختن ساختار و قدم بعدی رشد. این نشانه با معماری تصویر اصلی لندینگ هماهنگ است.

سه جهت بررسی‌شده: «درگاه رشد» (گزینه اجراشده)، «الف صعودی» (حرف‌نشان زاویه‌دار)، «شبکه افزا» (نشانه مدولار). جهت اول به دلیل خوانایی و هماهنگی با سایت انتخاب شد.

- اصلی: آبی #1948DE، نارنجی #EF975B.
- زمینه تاریک: آبی روشن #A8BFFF، همان نارنجی.
- فایل‌های SVG نماد، نسخه تیره، سیاه، سفید و ترکیب افقی در این پوشه هستند.
- نماد تماماً مسیر برداری است. نوشته در ترکیب افقی SVG متن زنده است و برای چاپ باید با فونت Vazirmatn به Outline تبدیل شود.
- فضای خالی پیرامون: حداقل ۸ واحد از نمای ۶۴ واحدی. حداقل اندازه پیشنهادی نماد: ۲۴ پیکسل؛ favicon زمینه‌دار برای اندازه‌های کوچک‌تر تهیه شده است.
- نماد را نکشید، نچرخانید و سایه یا گرادیان اضافه نکنید.
- این تحویل شامل بررسی یا تضمین ثبت علامت تجاری نیست.
